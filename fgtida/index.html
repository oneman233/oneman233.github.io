02 / EXPLORE THE QUESTIONS

Make trust
a concrete conversation.

Four lenses for understanding trust and identity. The Focus Group’s Terms of Reference define its formal scope.

Read the Terms of Reference ↗
TRUST
IN CONTEXTIDENTITYAUTHORITYEVIDENCE

Trust is a decision about an action and its context, rather than a permanent label.

01Identity & interoperability+

How can an agent’s identity be understood across services and organizations?

Starting points: identifiers, credentials, human–agent binding and interoperability.

02Authority & delegation+

If I authorize agent A, may it delegate to agent B?

Questions include permitted actions, constraints, delegation scope and expiry.

03Trust over time+

If the model, tools or context change, does the trust decision still hold?

Explore runtime checks, state changes and when human intervention is needed.

04Evidence & privacy+

How can we inspect an action without disclosing unnecessary personal information?

Consider verifiable records, necessary disclosure and limits on access to evidence.

A FEW USEFUL ANSWERS

Before you begin.

What is agentic AI?+

Here it means AI systems that plan, use tools and execute tasks toward a goal. For example, searching flights and initiating a booking within granted authority.

Is this work already an international standard?+

Focus Group technical reports and specifications are not ITU-T Recommendations. Check the official page and each repository for a document’s status.

Is this an official page?+

This is an independently created introduction to FG-TIDA. Refer to ITU for authoritative scope, participation requirements and meeting arrangements.
