请完整上传以下五个文件，不要只覆盖原来的三个文件：

| 文件 | 用途 |

| `index.html` | 唯一 HTML 入口；中文正文预渲染，英文通过页内语言按钮切换 |

本包不再包含 `en.html`。若你已上传过旧版，可删除旧的 `sg17/en.html`，避免保留过时副本。本次未修改配置文件或线上仓库。

## 访客统计的口径

使用开源项目 [soxft/busuanzi](https://github.com/soxft/busuanzi) 的公共服务，与 busuanzi.cc 和旧版 ibruce 服务不是同一服务。

- `page_uv`：该页面去重后的访客估算数，不等于可验证的自然人人数。
- `page_pv`：该页面的浏览次数；刷新或重新打开页面会增加浏览次数。
- 中英文版统一使用 `https://oneman233.github.io/sg17/` 作为统计标识，因此不是整个博客的访客数，也不会因主题参数分成不同页面。
- 一次文档加载只发起一次统计请求；页内语言切换、主题筛选和演示点击不增加访问计数。
- 本地预览和其他域名不发送计数请求。若以后更换域名或路径，请更新 `loadAnalytics()` 中的正式站点判断、统计标识、分享地址和 HTML 元信息。
- 服务成功响应后才显示数字。超时、断网、拦截或无效响应显示“统计暂时不可用”，不会生成假数字或把失败显示成 0。
- 服务返回的签名去重标识保存在浏览器本地。清理存储、设备或网络变化可能影响去重结果。
- 服务是外部公共服务，其可用性和数据保留由提供者负责。统计说明已放在页面底部的可展开说明中。

检查时，公共统计接口对此页面返回的已有数据为 0。历史访问如果此前没有接入该统计服务，就无法从静态 HTML 中恢复；上线后开始累计。

协议参考：[使用说明](https://github.com/soxft/busuanzi/wiki/usage)、[API 文档](https://github.com/soxft/busuanzi/wiki/api)。

## 发布后快速验收

1. 从博客导航打开 `/sg17/`，切换 EN / 中文，确认仍在同一个页面，样式、图标和封面资源正常。
2. 用手机检查顶部菜单、四宫格、卡片和演示区域是否完整可读。
3. 点击“查看日程”和“尝试付款”，分别看到允许与拦截结果。
4. 展开一个概念说明后切换语言，确认说明仍展开。
5. 检查页面底部统计。网络正常时显示服务器数字；如果不可用，检查浏览器是否拦截统计域名。
6. 从新窗口打开复制的英文链接，确认仍为英文。

后续修改内容时，请同步修改 `index.html` 的中文静态文本以及 `script.js` 中相应的中英文内容。英文切换需要 JavaScript；禁用脚本时仍能阅读中文正文。社交平台不执行脚本时使用默认的中文页面描述和统一分享封面。
